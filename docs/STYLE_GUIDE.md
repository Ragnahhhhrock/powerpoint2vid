# PowerPoint2Vid Design System & Style Guide

Single source of truth: the tokens in `:root` of `styles.css`. Never hard-code colours, sizes or radii elsewhere. A live version is at `/style-guide.html`.

## Brand
- **Name:** PowerPoint2Vid (wordmark: "PowerPoint" in ink, "2Vid" in violet).
- **Voice:** plain, confident, short sentences. Say what it does ("Turn slides into narrated videos"). No hype, no jargon.
- **Primary keyword:** "PowerPoint to video converter" appears in the title, H1, meta description and first paragraph.

Gradient: violet-500 to coral-500, used only for the H1 highlight, progress bar and icon.

## Typography
Inter for body and UI, falling back to the system UI stack. Weights 400/500/600/700/800.
Display (homepage headings only): Bricolage Grotesque via `--font-display`, 800 weight, width axis 92, tracking -0.035em. Hero size `--fs-display`.
H1 `--fs-2xl` 800, tight tracking (-0.035em); H2 `--fs-xl` 800; H3 `--fs-md` 700; body `--fs-md` 1.6 line height; small `--fs-sm`/`--fs-xs`.

## Spacing, shape, depth
4px base scale `--s-1…--s-9`. Radii: 8 (inputs), 14 (cards), 22 (panels), pill (buttons). Shadows: `--shadow-sm`, `--shadow-md` (panels), `--shadow-lg` (video stage, violet glow).

## Components
- **Button:** pill, 44px min height, bold 15px. Primary violet, accent coral (one per view), ghost white with border.
- **Panel/Card:** white, 1px `--border`, radius 22/14.
- **Drop zone:** dashed 2px ink-300; hover/drag turns violet.
- **Form fields:** 8px radius, 1px ink-300 border, labels 600 weight above field.
- **Tabs, details/FAQ, progress bar, filmstrip thumbnails** as in `styles.css`.

## Accessibility
- WCAG AA contrast; visible 3px violet focus ring on every control; 44px touch targets.
- Skip link, semantic landmarks, labelled controls, `aria-live` status updates.
- `prefers-reduced-motion` disables UI transitions.

## Homepage & motion
- Homepage-only styles live in `home.css`, behaviour in `js/home.js` (no dependencies).
- Dark "screening room" sections (`--ink-950`) carry `data-dark`; the fixed header turns dark over them.
- One load sequence: headline lines build in, a coral playhead sweeps across and renders outline type solid, then the slide deck deals onto the stage.
- One scroll sequence: the pinned "How to convert" story (deck drop, notes read aloud, slide builds with captions, export) driven by `--p1…--p4`.
- Everything else moves only on user action (deck tilts toward the pointer, style tiles preview on hover/focus and pick the style on click).
- Easing tokens `--ease-out`, `--ease-spring`. `prefers-reduced-motion` shows every sequence in its final state.
